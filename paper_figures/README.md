# Paper Figures

The six PDFs in this folder are the vector manuscript figures:

- `kappa_evolution_3d_single.pdf`
- `theorem_dashboard.pdf`
- `corrugated_six_junction_diagnostics.pdf`
- `practical_stainless_zro2_corrugated_diagnostics.pdf`
- `mesh_strategy_triptych.pdf`
- `mesh_comparison_refined_single.pdf`

Each PDF has a PNG copy with the same stem so that the plots render directly on
GitHub. The notebook displays the PDFs. A fresh run creates `generated/` for
new figures, leaving the included versions unchanged.
